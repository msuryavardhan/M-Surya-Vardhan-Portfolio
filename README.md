## 🚀 GitHub Pages Deployment Guide

### Step 1 — Copy Resume PDF
Place your resume PDF inside `assets/resume/`:
```
assets/resume/Manchikanti_Surya_Vardhan_Resume_Latest.pdf
```

### Step 2 — Create GitHub Repository
1. Go to [github.com](https://github.com) and sign in
2. Create a new repository named exactly: `manchikanti-suryavardhan.github.io`  
   *(Replace `manchikanti-suryavardhan` with your GitHub username)*
3. Set it to **Public**

### Step 3 — Upload Files
```bash
git init
git add .
git commit -m "Initial portfolio deploy"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-USERNAME.github.io.git
git push -u origin main
```

### Step 4 — Enable GitHub Pages
1. Go to repository **Settings → Pages**
2. Source: `Deploy from a branch`
3. Branch: `main` / `root`
4. Click **Save**

### Step 5 — Access Live Site
Your portfolio will be live at:  
`https://YOUR-USERNAME.github.io`
